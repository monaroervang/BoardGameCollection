# ADR 003: Application-generated UUIDv7 identifiers

## Status

Accepted

## Context

The system needs a consistent strategy for identifying entities such as
BoardGame, User, Item, and Loan.

ADR 001 originally selected database-generated integer identifiers using
SQL Server Identity columns.

As the system design developed, application-generated identifiers were
reconsidered. The system will expose entities through APIs and may later
be divided into separate services.

With database-generated integer identifiers, an entity does not receive
its final identifier until it has been persisted. Application-generated
identifiers allow an entity to have its identity immediately when it is
created.

Random UUIDs were also considered. However, UUIDv7 identifiers are
time-ordered, which makes them more suitable for database indexing than
fully random UUIDs while retaining the advantages of globally unique
identifiers.

.NET 10 provides native support for creating UUIDv7 values through
`Guid.CreateVersion7()`.

## Decision

Entity identifiers use the .NET `Guid` type and are generated by the
application using UUID version 7.

Entities generate their identifier when they are created.

Example:

```csharp
public Guid Id { get; private set; } = Guid.CreateVersion7();
