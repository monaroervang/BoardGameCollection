\# ADR 001: Database-generated integer IDs



\## Status



Superseded by ADR 003



\## Context



The system needs a consistent strategy for generating identifiers for

entities such as BoardGame, User, Item, and Loan.



The application uses Entity Framework Core with SQL Server for persistence.



We considered whether IDs should be generated by the application or by

the database.



\## Decision



Entities use `int` as their primary key, and IDs are generated by

SQL Server when an entity is inserted into the database.



Entity constructors do not require an ID when creating new domain objects.



EF Core is configured so that IDs are generated when entities are added.



Example:



```csharp

builder.HasKey(bg => bg.Id);



builder.Property(bg => bg.Id)

&#x20;   .ValueGeneratedOnAdd();
